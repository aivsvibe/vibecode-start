1 Инструкция по 3-м главным кнопкам управления

В верхней панели управления расположены 3 фундаментальные кнопки для полного цикла работы с задачами:

+
1. Кнопка «Добавить»

Открывает окно создания новой задачи. Вы можете ввести своё название, выбрать одну из 5 категорий (Промптинг, Вайб, Шиппинг, Кофе, Тюнинг), указать сложность и время. Внутри окна есть кнопка «🎲 Сгенерировать», которая мгновенно подставляет случайную задачу из базы 180+.

🗑️
2. Кнопка «Удалить»

Умное меню очистки:
• Удалить только выполненные — в 1 клик стирает все завершенные пункты с галочками.
• Очистить весь список полностью — полный сброс для старта чистого дня.
• Также у каждой отдельной задачи есть индивидуальная кнопка удаления 🗑️.

💾
3. Кнопка «Сохранить»

Мгновенно формирует и скачивает на ваш компьютер локальный JSON-файл tasks_ГГГГ-ММ-ДД.json. Вы можете положить его в проект VS Code для Cursor/Copilot. Кроме того, состояние автоматически сохраняется в памяти браузера.

3 Чекбоксы и начисление баллов («Скилл» & «Вайб»)

Слева от каждой задачи расположен интерактивный квадратный чекбокс. Когда вы кликаете по чекбоксу или названию задачи:

✓
Механика работы чекбокса:
  • Задача перечёркивается и подсвечивается как выполненная.
  • Прогресс-бар дня в шапке увеличивает процент завершения.
  • Вам мгновенно начисляются XP в ветки «Скилл» и «Вайб» с учётом категории и сложности.
  • В правом нижнем углу всплывает уведомление с точным количеством полученных очков.
  • В разделе «Прокачка» автоматически растёт уровень звания, двигается полоска опыта и пополняется «История начисления баллов».
  • Если снять галочку — очки корректно вычитаются назад.

4 Инструкция пользования в VS Code & Работа с tasks.json

Этот файл представляет собой автономное решение «Всё в одном» (HTML + CSS + JavaScript), которое готово к запуску в VS Code без настройки Node.js или веб-серверов:

🚀 Как запустить файл в VS Code:
  1. Сохраните этот файл как index.html (или vibe_planner.html) в вашей рабочей папке VS Code.
  2. Установите расширение Live Server в VS Code (если ещё не установлено).
  3. Кликните правой кнопкой мыши по файлу index.html в проводнике VS Code и выберите «Open with Live Server».
  4. (Или просто дважды кликните по файлу в проводнике Windows/Mac — он сразу откроется в браузере!).
📁 Как использовать tasks.json в связке с AI в VS Code:
1. Нажмите зелёную кнопку «💾 Сохранить» в приложении.
2. Переместите скачанный JSON-файл в корень проекта в VS Code и переименуйте в tasks.json.
3. Теперь в Cursor, GitHub Copilot или Claude вы можете написать: «Посмотри задачи на сегодня в tasks.json и помоги выполнить текущую невыполненную задачу»!

Перед началом работы вайбкодера знай, что тебе не нужно сразу платить огромные деньги за крутые ИИ модели, для начала поработай с базой, обязательно спрашивай у агентов за что отвечает та, или иная строчка кода, без понимания своих инструментов далеко не уйдешь.

Всегда проверяй каждую линию и каждую кнопку перед следующим шагом, иначе все сломается и починить уже будет намного сложнее! освоился? создавай портфолио, добавь туда пару своих проектов, покажи свои навыки, и только теперь можешь пробовать выйти в продажи.

(п.с. используй платные ИИ если ты уже создал достаточно много проектов и понимаешь код, а еще лучше когда выйдешь в продажи)
1. Начни с базы
Бесплатных моделей хватает для обучения и десятков первых проектов.
2. Понимай код
Спрашивай у агента суть строк и проверяй каждую кнопку перед шагом.
3. Продажи позже
Оформи 2-3 кейса в портфолио, и лишь потом бери платные ИИ и заказы.
